**Hệ thống đặt lịch tư vấn / hẹn gặp giảng viên**

1. Giới thiệu dự án

Hệ thống đặt lịch tư vấn / hẹn gặp giảng viên là một dự án Web nhằm hỗ trợ sinh viên đăng ký lịch hẹn với giảng viên một cách thuận tiện và hiệu quả.
Hệ thống hướng tới việc giúp sinh viên lựa chọn thời gian phù hợp để đăng ký tư vấn hoặc hẹn gặp giảng viên, đồng thời hỗ trợ giảng viên quản lý các lịch hẹn.

2. Mục tiêu của dự án

- Hỗ trợ sinh viên đăng ký lịch hẹn với giảng viên.
- Giúp việc quản lý lịch tư vấn thuận tiện hơn.
- Hạn chế việc đăng ký lịch hẹn thủ công.
- Áp dụng kiến thức lập trình Web và cơ sở dữ liệu vào một bài toán thực tế.

3. Công nghệ sử dụng

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

4. Cấu trúc project

project-nhom/
│
├── README.md
├── index.php
├── about.php
├── db.php
├── header.php
└── footer.php

#Mô tả các file
- index.php: Trang chính của hệ thống.
- about.php: Trang giới thiệu nhóm và đề tài.
- db.php: File kết nối cơ sở dữ liệu.
- header.php: Thành phần phần đầu trang.
- footer.php: Thành phần phần cuối trang.
- README.md: Tài liệu giới thiệu và hướng dẫn chạy project.

5. Yêu cầu môi trường

Để chạy project trên máy tính cá nhân, cần:
- XAMPP
- Trình duyệt Web như Google Chrome, Microsoft Edge hoặc Firefox.

6. Cách chạy project Local

Bước 1: Khởi động XAMPP
Mở XAMPP Control Panel và khởi động:
start Apache
tart MySQL

Bước 2: Đưa project vào thư mục htdocs

Copy thư mục project-nhom vào:
C:\xampp\htdocs\

Đường dẫn project:
C:\xampp\htdocs\project-nhom\

Bước 3: Chạy project

Mở trình duyệt và truy cập:
http://localhost/project-nhom/

Bước 4: Truy cập trang giới thiệu

Để xem trang giới thiệu nhóm và đề tài, truy cập:
http://localhost/project-nhom/about.php

7. Cơ sở dữ liệu

Project dự kiến sử dụng MySQL để lưu trữ dữ liệu.

Có thể quản lý cơ sở dữ liệu thông qua:
http://localhost/phpmyadmin/

File db.php được sử dụng để kết nối PHP với cơ sở dữ liệu MySQL.
